# Hidden Value MVP Roadmap

The project advances only after the current vertical slice has been assessed for feel and usability.

## Phase 1 — Pocket Watch Vertical Slice

One polished loop: inspect the watch, find `925`, narrow the estimate, buy for `$40`, brush, polish, appraise at `$118`, sell and receive `$78` profit.

## Phase 2 — Generic Item System (in progress)

Generalize item definitions, item instances, clues, restoration tools, renderer configuration, localized content and scene composition.

## Phase 3 — Vintage Camera (implemented)

Add the second data-driven item with lens inspection and a new clue pattern.

## Phase 4 — Fake Luxury Watch (implemented)

Add a suspicious luxury watch with UV and serial inspection clues on the shared item loop.

## Phase 5 — PixelBox 84 (implemented)

Add disassembly clues and a quick versus precision repair decision for a rare console.

## Phase 6 — Painting (next)

Add provenance inspection and the dealer/auction decision.

## Phase 7 — Workshop Meta

Add workshop progression after the item loop is proven.

## Phase 8 — Collections

Add collection storage and display after enough items exist.

## Phase 9 — Auction

Add the auction loop and risk/reward choices.

## Phase 10 — 30-minute onboarding

Connect the first several item stories into a guided first session with optional actions kept secondary to the main loop.

## Phase 11 — Production save and analytics

Harden persistence, migration, event validation and privacy-aware production analytics.

## Phase 12 — Ad mocks

Add optional rewarded and interstitial UX behind the platform abstraction, still testable on WebAdapter.

## Phase 13 — YandexAdapter

Check the current official Yandex Games documentation, then implement the adapter without changing gameplay systems.

## Phase 14 — Yandex QA / soft launch

Run portal QA, mobile device checks, performance checks and a controlled soft launch.

## Phase 15 — CrazyGamesAdapter

Check the current official CrazyGames documentation, then implement and test the adapter independently.
